# Global TV｜全球电视直播台

固定网址：https://songshangsheng040-web.github.io/global-tv/

免费的官方电视直播导航，优先适配 Mac 桌面 Chrome。无付费 API、无用户账户、无第三方直播源。20 个频道记录，覆盖 14 个国家和地区（以 channels.json 实际统计为准）。

## 使用

打开网址，搜索或筛选频道，再点击“前往官方直播”。在新标签页使用官方播放器观看和全屏。本站不代理转播，不绕过 iframe、地区或登录限制。所有频道的嵌入支持暂未确认，因此采用官方网页播放。

点击 ☆ 收藏；从本站点击直播入口时记录最近观看。数据保存在当前网址的 localStorage；不会上传。更换浏览器、清除网站数据或无痕浏览不会保留原记录。关闭存储时仍可使用网站，但无法持久保存。

## Mac 双击启动

下载 `全球电视台.command`，双击使用。文件仅检查 Chrome 并打开固定线上网址，无本地服务器。若下载后执行权限丢失，在终端执行 `chmod +x` 后拖入文件路径并回车。之后代码和频道更新不需要再次下载此文件。

## 英语新闻实时中文字幕

1. 更新 Chrome，在地址栏打开 `chrome://settings/accessibility`。
2. 开启“实时字幕”，添加英语并等待语言包完成。
3. 开启“实时翻译”，将字幕翻译为“中文（简体）”。
4. 打开官方直播并播放有声内容，Chrome 会显示字幕浮窗。可拖动浮窗；在官方播放器全屏。

实时字幕和实时翻译由 Chrome 提供，不是本站功能。翻译会将字幕发送给 Google；可用性和准确率受版本、设备、语言、网络和音质影响。本站不能读取浏览器字幕，不提供自制双语字幕。

官方说明：https://support.google.com/chrome/answer/10538231?hl=zh-Hans

## 来源与验证范围

频道数据只链接广播机构官方网页或经官方资料确认的官方 YouTube 频道。`lastVerified` 是最后一次入口核对日期，不代表音视频已通过完整播放测试。`verification` 逐项记录证据和核对限制：

- **入口已核对**：已读取官方直播入口或官方直播说明；不保证任何地区均可播放。
- **待播放验证**：入口属于官方机构，但自动抓取受阻或页面依赖脚本，未验证音视频。
- **地区 / 登录限制**：TVNZ 1 通常要求新西兰地区与免费登录。
- **按播出时段 / 按活动时段**：公视、NASA 不承诺 24 小时直播。

直播电视节目表可能包含录播节目，这是官方线性播出；本站不把单个录播视频包装成直播。Bloomberg 等频道可能调整观看时限或登录规则。没有付费源或未经授权的 m3u8。官网版权属于各自机构。

## 新增和更新频道

在 GitHub 编辑 `channels.json`，复制一条记录并使用唯一的 `id`。填写 `name`、`country`、`language`、`category`、`website`、`liveUrl`、`embedSupported`、`lastVerified`、`status`、`verification`、`restrictions`、`description`、`short`。URL 必须为 HTTPS。核对官方直播页、频道身份及播放限制，不能把未测试写成可播放。未确认嵌入时填 `null`。当前版本只提供官方外链播放，改为 `true` 不会自动启用内嵌播放器。

修改顶层 `updatedAt`，提交 main 分支。GitHub Pages 从 main 根目录自动发布。网页每次加载和点击“更新频道”会用时间戳及 `cache: no-store` 获取新 JSON，收藏和历史不受频道更新影响；页面代码如有缓存，刷新即可。未注册 Service Worker。数据加载失败会显示错误，不会把旧缓存冒充最新数据。

## 发布与验证

GitHub Settings → Pages → Deploy from a branch → main → /(root) → Save。根目录提供 `.nojekyll`，无需 npm、构建或付费服务。每次 main 更新由 Pages 自动部署。发布后检查首页、app.js、style.css、channels.json 均可访问，并测试搜索、筛选、收藏、记录与指南。

本地测试可使用 `python3 -m http.server 8765`，然后用 Chrome 打开 `http://localhost:8765`。直接双击 index.html 不能通过 fetch 读取频道 JSON。

官方播放器提供播放与全屏。未实现：站内音视频播放器、自制双语字幕、跨设备同步、自动探测所有地区的直播健康状态。当前目录适合继续审慎增加频道，不追求未经验证的数量。
