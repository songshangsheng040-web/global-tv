CHROME ON MAC

开启实时中文字幕

  1. 在 Chrome 地址栏输入 chrome://settings/accessibility，打开「无障碍」。
  2. 开启「实时字幕」，在支持的语言中添加或选择英语，等待语言文件下载完成。
  3. 开启「实时翻译」，将「将字幕翻译为」设置为「中文（简体）」。
  4. 点击「频道主页」或「直播列表」打开 YouTube，然后选择正在直播或其他官方节目，点击播放器播放并确保有声音。字幕窗口由 Chrome 显示，可拖动位置。
  5. 全屏请点击官方播放器的全屏按钮，或使用 Chrome 菜单「显示 → 进入全屏幕」。

实时翻译会将字幕发送给 Google 翻译。功能可用性取决于 Chrome 版本、设备、语言和网络；如果没有该开关，请更新 Chrome 并查看官方说明。本站无法读取或控制 Chrome 的字幕窗口，不提供自行生成的双语字幕。
